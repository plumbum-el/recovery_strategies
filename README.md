# Лабораторная работа №5 — recovery_strategies

## Назначение
Базовое SPA на **React + TypeScript + Vite** для гостевого просмотра стратегий восстановления. Создано на основе темы, названий, медиа и структуры ЛР4. **В ЛР5 работают ровно две страницы: лента и плитка**. Четыре пункта меню присутствуют, но «Добавление» и «Вход» заблокированы. React-Bootstrap используется для интерфейса. Redux и Context отсутствуют.

## Запуск на Windows (VS Code)
1. Установить Node.js (если его ещё нет).
2. Открыть в VS Code **эту папку**, где лежит `package.json`.
3. В терминале выполнить `npm install` (первый запуск требует интернет).
4. Выполнить `npm run dev`.
5. Открыть адрес Vite, обычно `http://127.0.0.1:5173/`.
6. Для проверки сборки: `npm run build`.

**Не запускайте** Docker, PostgreSQL, Redis, MinIO или FastAPI: фронтенд не обращается к ним. Данные берутся только из `src/data/mockStrategies.ts`, медиа из `public/media`.

## Страницы, кнопки и поля

### 1. Лента
- Показывает одну стратегию за раз: видео, название, описание, время восстановления, стоимость и число лайков.
- Кнопка**«Следующая»** перелистывает локальную коллекцию.
- Видео имеет стандартные элементы управления браузера; данные и число лайков только отображаются, запросы к серверу не отправляются.

### 2. Плитка (каталог)
- Сетка карточек с изображением, названием, описанием, временем, стоимостью и числом лайков.
- Поле **«Поиск стратегии по названию»** фильтрует по подстроке без учёта регистра.
- Поля **«Время от, мин»** и **«Время до, мин»** задают границы диапазона.
- Кнопка **«Сбросить»** очищает фильтры.
- Нажатие на карточку открывает выбранную стратегию в ленте.

### Нижняя навигация (4 пункта)
- **Лента** — доступна.
- **Добавление** — недоступно в ЛР5.
- **Плитка** — доступна.
- **Вход** — недоступно в ЛР5.

## Mock и изображения/видео по умолчанию
- `src/data/mockStrategies.ts` — коллекция из 6 локальных стратегий. Две стратегии имеют `image_url: null` и `video_url: null`, чтобы показать fallback.
- `src/components/Media.tsx` — `StrategyImage` и `StrategyVideo`. Если путь пустой, берутся `/media/default_image.png` и `/media/default_video.mp4`. При ошибке загрузки изображения также включается fallback; для видео предусмотрена замена источника при ошибке элемента video.
- `public/media` — локальные медиа из ЛР4. Никакого S3.

## React-компоненты, props и хуки
- `App.tsx`: `useState` хранит текущую страницу и выбранный ID. Props `page`, `onNavigate`, `onOpen`, `initialId` связывают компоненты.
- `pages/CatalogPage.tsx`: `useState` для фильтров, `useMemo` для отфильтрованного списка.
- `components/StrategyFilter.tsx`: props `values`, `onChange`, `onReset`. Компонент не хранит фильтр внутри — получает значения от родителя.
- `components/StrategyCard.tsx`: props `strategy` и `onOpen`.
- `pages/FeedPage.tsx`: `useState` для текущей карточки, `useEffect` для выбора карточки, открытой из каталога.
- `components/Media.tsx`: `useState` для переключения на медиа по умолчанию при ошибке.
- `components/BottomNav.tsx`: props `page` и `onNavigate`.

**Network:** запросы к `localhost:5173` за файлами приложения и локальными медиа допустимы. Запросов к `/api/`, PostgreSQL и S3 быть не должно. В Network можно включить фильтр Fetch/XHR, чтобы подтвердить отсутствие запросов к API.
